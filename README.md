# 献祭 (Xianni) — 修仙版吸血鬼幸存者

使用 **Phaser 3 + Vite + TypeScript** 开发的 Web 端 roguelike 生存游戏。
以小说《仙逆》为题材:**法术是攻击手段,遗物决定成长方向,满级的法术与专属遗物融合成道法**。

> 详细数值与规则见 `docs/build设计.md`、`docs/地图设计.md`、`docs/怪物设计.md`。
> 三份文档是设计基准,与代码冲突时以文档为准。

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run typecheck  # 类型检查(本项目唯一的自动化保障)
npm run build      # 类型检查 + 生产构建
npm run preview    # 本地预览生产构建
```

本项目**没有测试框架和 lint**,`npm run typecheck` 是唯一的自动化关卡。
`tsconfig.json` 开启了 `strict` + `noUnusedLocals` + `noUnusedParameters`。

## 手机端(PWA)

生产构建就是一个可安装的 PWA:**添加到主屏幕**后全屏运行、横屏锁定、断网可玩。
把 `dist/` 丢到任意 HTTPS 静态托管即可,没有原生工具链。

```bash
npm run build     # 产出 dist/(含 manifest.webmanifest、sw.js、icons/)
npm run preview   # 本地看效果。⚠️ Service Worker 只在 https 或 localhost 下注册
```

- **iOS**:Safari 打开 → 分享 → 「添加到主屏幕」。
  iOS 不支持 `screen.orientation.lock` 的自动调用,竖屏时会有一层「请横屏游玩」的遮罩挡住。
- **Android**:Chrome 打开 → 菜单 → 「安装应用」/「添加到主屏幕」。
- 离线清单由 `scripts/vite-plugin-offline.mjs` **在构建时从真实产物生成** ——
  Vite 给文件名加了内容哈希,手写的清单必然过期,而那种过期只在你已经断网、
  点开图标的时候才显形。改了图标配色就重跑 `npm run icons`(图标是脚本画的,不进仓库)。

移动端相关的代码集中在 `src/utils/mobile.ts`(离线注册 / 横屏锁定 / 切后台自动暂停)。
触屏摇杆在 `src/utils/InputManager.ts`,是输入不是外壳,故意分开放。

## 玩法

操控王林自动战斗,击杀妖物获取**灵气**,灵气转为**修为**推进等级。
每次升级弹出**悟道三选一**。法术满 8 级 + 对应专属遗物满 5 级之后,
**开任意宝箱**即可道法融合,得到一门质变的新法术。

### 核心循环

1. **索敌开火** — 五门法术各自的形态自动生效(直射 / 环绕 / 扇形 / 连锁 / 火海)
2. **拾取灵气** — 靠近自动吸附,化为修为
3. **悟道** — 每次升级暂停,三选一(新法术 / 法术升级 / 新遗物 / 遗物叠层 / 消耗品)
4. **开箱** — 精英必掉洞府宝箱(木匣 1 次 / 玉盒 3 次 / 金匮 5 次悟道)
5. **道法融合** — 法术 8 级 + 专属遗物 5 级 → 下次开箱时融合,专属遗物被吸收、腾出遗物槽
6. **陨落** — 气血归零 → 结算 → 重新开始

### 五门法术 · 五种几何

| 法术 | 几何 | 打法 | 进化 |
|---|---|---|---|
| **火球术** | 追踪直线飞弹 | 自动锁敌,命中爆裂;第 3 级起点燃 | 焚天·火海(落点灼烧区,可叠 3 层) |
| **寂灭指** | 朝向直线贯穿 | 朝面向射出指气,穿透一条线 | 化魔指(光束 ×5、全屏、穿透无限、破魔) |
| **剑阵** | 环绕自身 | 飞剑绕身,无需瞄准 | 斩罗决(每 4 秒收束斩出放射剑气) |
| **厚土术** | 前方扇形推进 | 分 3 段推进 + 推挤聚怪;**满级起沙浪可打落敌方弹道**(首领的除外) | 山崩地裂(180° + 崩墙阻挡与眩晕) |
| **五雷正法** | 连锁弹射 | 瞬时弹射,叠感电增伤,怪越多越强 | 五雷轰顶(感电满层目标被天雷自动点名) |

五者的**碰撞形状两两不同**:线 / 环 / 面 / 链 / 滞留。关闭特效只看碰撞体时仍能一眼分辨。

### 法位 · 随境界成长

法术槽**开局只有 2 格**,每突破一次大境界开一格:

| 境界 | 凝气 | 筑基 | 结丹 | 元婴 | 化神 |
|---|---|---|---|---|---|
| 法位 | **2** | 3 | 4 | 5 | 6 |

五门法术、开局两格 —— 前 16 级你必须先决定「这一局走哪两条路」。
**越早突破越赚**,这是全局唯一一条由境界直接给出的 Build 压力。

### 遗物 12 件 · 6 个槽

遗物槽固定 6:5 件专属 + 7 件通用 = **12 选 6 必须放弃 6 件**,
中后期的取舍压力集中在这里。

- **5 件专属**(天逆珠灵液 / 散魔铠甲 / 仙剑 / 厚土印 / 紫金雷葫):只强化对应法术,
  并且是该门融合的必要前置。**只有已学会对应法术之后才会进卡池**。
- **7 件通用**(天逆珠 / 古神之血 / 定身术 / 气运 / 遁术 / 储物袋 / 灵石):自由组合。

### 境界体系

七个大境界,从「凝气·一层」到「问鼎·圆满」,是 HUD 上的身份感与乘算加成。
**境界不再卡升级** —— 突破只给一次乘算收益,不需要任何道具。

| 境界 | 层数 | 命名 | 法位 |
|---|---|---|---|
| 凝气 | 15 | 一层 ~ 十五层 | 2 |
| 筑基 | 5 | 初期 ~ 圆满 | 3 |
| 结丹 | 5 | 初期 ~ 圆满 | 4 |
| 元婴 | 5 | 初期 ~ 圆满 | 5 |
| 化神 / 婴变 / 问鼎 | 各 5 | 初期 ~ 圆满 | 6 |

### 刷怪节奏

怪物**按时间一只只引出来**,而不是几分钟换一批。`ENEMY_INTROS` 里每只怪只写一行
「第几秒登场」,新怪先按三成权重出现、再在一两分钟内变密 —— 中间那几十秒正好用来认它。

| 登场 | 怪 | 教什么 |
|---|---|---|
| 0:00 | 山野妖兽 | 基准:直线冲脸 |
| **0:30** | 铁甲蚁 | 快而脆:跑不过的东西未必肉 |
| 1:30 | 腐尸 | 慢而厚:第一只两刀怪,「打不死就绕开」是真选项 |
| 3:00 | 阴魂 | 屏内现身,「后方」失效 |
| 5:00 | 火灵 | 自爆:不让它靠近就是输出 |
| 7:00 | 蛊虫 | 清屏 ≠ 清干净 |
| **8:00** | 散修 | **第一道弹道**:必须朝它走 |
| 10:00 | 尸修 | 潜行 + 更厚 |
| 12:00 | 石傀 | 护甲:堆穿透而不是堆伤害 |
| 14:00 | 魔道修士 | 合围 + 弹道 |
| 16:00 | 铁甲兽 | 重甲推进 |
| 19:00 | 上古凶兽 | 冲锋:被单只怪追着跑 |
| 23:00 | 界外之魂 | 拉拽:站位不再由你决定 |

两条硬规矩由 `validateOpeningDifficulty()` 在启动时检查,破掉会直接报警:

- **有弹道的怪不得早于 8:00** —— 远程要求「主动朝它走」,开局教的是「跑动中清场」,
  两种要求叠在一起只会互相抵消
- **开局 30 秒内登场的怪必须被 1 级起手法术一击必杀** —— 两刀怪会把「打怪」变成「被怪追」

### 地图与环境机制

**朱雀星** —— 环境机制「灵脉地热」:地脉随机喷发火柱,喷发前 1.2 秒给出预警圈,
被逼在「怪群」与「火柱」之间选站位。地图机制、世界尺寸、地面配色全部走
`src/config/MapConfig.ts`,加图不改代码。

### 首领

**朱雀(成体)** 在 10:00 登场,三阶段:
火羽扇 → 火雨(落点预警圈)→ 半血**浴火重生**(回满一次并狂暴)。
首领表在 `src/config/BossConfig.ts`,加一只 = 一行怪 + 一段阶段表。

    ├── config/                 # 全部数值都在这里,不要散落到逻辑里
    │   ├── GameConfig.ts            # Phaser.Game 配置
    │   ├── SpellConfig.ts           # 5 门法术 × 8 级数值表(逐级手写)
    │   ├── EvolutionConfig.ts       # 5 条道法融合配方
    │   ├── RelicConfig.ts           # 12 件遗物

    │   ├── MapConfig.ts             # 地图与环境机制
    │   ├── BossConfig.ts            # 首领时间表与阶段
    │   ├── EnemyConfig.ts / WaveConfig.ts / EliteConfig.ts / MechanismConfig.ts

    │   ├── GameScene.ts             # 编排中心:装配全部系统
    │   ├── UIScene.ts               # HUD(拉取式,直接读 GameScene)
    │   ├── UpgradeScene.ts          # 悟道三选一面板
    │   └── GameOverScene.ts
    ├── entities/
    │   ├── Player / Enemy / Projectile / Pickup / EnemyShot / DamageText / BloodTide

升级与开箱时 `UpgradeScene`;死亡时 `GameOverScene`)。

## 美术

MVP **完全使用程序化生成的精灵** —— `src/utils/AssetGenerator.ts` 用
`Phaser.Graphics` 绘制后 `generateTexture()`,没有任何二进制素材依赖,启动即可玩。
敌人与首领的贴图由 `archetype` × 配置配色参数化生成,**加一只怪 = 加一行配置**。

真实素材丢进 `src/assets/` 即自动生效,**文件名必须与纹理键完全一致**
(`src/assets/characters/enemy_beast.png` → 键 `enemy_beast`,子目录随意)。
`import.meta.glob` 在构建时枚举目录,所以只有真正存在的文件才会进加载队列,
少写一个字母也不会变成一次无声的 404。启动时控制台会打一份缺失清单。
尺寸/命名/配色规则见 `docs/美术素材规格.md`。

- **崩墙的阻挡**只挡敌人、不做寻路:敌人贴着墙滑动,不会绕行
- 局外的**灵石强化树**(道行 / 护体 / 寿元 / 回春 / 神识 / 遁速 / 气运 / 聚宝)
  尚未实现,灵石目前只累计与展示
- 地图与首领都只落地了第一份(朱雀星 / 朱雀),其余五张图与五只 Boss 待补
- 怪物图鉴仍是上一轮的十三种逼近几何,尚未按 T1–T8 重排
- 投掷物池(140)在五门满级同时开火时偏紧,极端情况下会丢弹
