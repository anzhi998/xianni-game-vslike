## ① 追踪弹：火球术 → 焚天·火海（projectile · aim: target）

```
玩家                                  自动锁最近敌人
 ● ·····························▶  ✳ ◆ 敌        ← 爆裂 45 + 点燃 10/s·4s
  ╲                                   ⭘⭘          ← 火海 r1.2格 · 28/s · 叠3层(3s)
   ● ···························▶  ✳ ◆ 敌
```

- **几何**：弹道追踪（自动锁最近敌人），命中在一点爆裂，不穿透；落点摊开圆形火海。
- **基础满级**：30 ×4 发 / 冷却 1.10s / 弹速 10 格/s / 点燃 10/s·4s（3 级起点燃）
- **焚天·火海**：45 ×4 发 / 火海 r1.2 格 · 28/s · 存续 3s · 同点最多叠 3 层；继承点燃
- **口径**：主伤害在地上不在弹上——直伤 4×45÷1.10 ≈ 164/s，火海才是跃升本体
- **强**：密集怪群（落点火海叠层）；**弱**：高速冲刺怪需预判落点

## ② 面向光束：寂灭指 → 化魔指（projectile · aim: facing）

```
                     ┌──────────────────────────┐  3 道齐射（总张角 0.24 rad）
玩家 ◆━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━▶  穿透 6 → 化魔指 ∞
                     └──────────────────────────┘
 面向 →    宽 0.4 格 ══进化══▶ 宽 2.0 格 · 射程全屏 · 减速 40%·3s · 破魔 30%
```

- **几何**：一条由玩家朝向决定的贯穿直线；多道齐射沿总张角逐道展开。
- **寂灭指满级**：36 ×3 发 / 冷却 1.40s / 穿透 6 / 射程 10 格 / 宽 0.4 格 / 减速 25%·2s（3 级起）/ 单体 ≈77/s
- **化魔指**：50 ×3 发 / 冷却 1.20s / 穿透 ∞ / 射程全屏 / 宽 2.0 格 / 减速 40%·3s / 破魔 30% / 弹速刻意压到 12 格/s（慢下来才读得出宽带）
- **强**：一线扫过成片湮灭，五路里唯一能从开局直通终局；**弱**：单体 125 比火球还低

## ③ 环绕飞剑：剑阵 → 斩罗决（orbiter）

```
        ✦           ✦           ✦
          ╲          │          ╱              剑阵: 2→6 把 · r1.0→1.45格
            ╲        │        ╱                转速 3.9 rad/s · 活 2 圈
       ──────╲      │      ╱──────            每只怪每圈中 1 次
        ✦ ────╲──── ●玩家 ────╱──── ✦        命中判定 16px 恒定
            ╱        │        ╲              冷却 = 存活期（场上剑数恒定）
          ╱          │          ╲
        ✦           ✦           ✦

  斩罗决: 8 把 · r2.2 格 · 7.0 rad/s + 每 4s 收束斩出剑气 ×8
              ↗  ↗
           ✦  ↑  ↑          剑气: 45 伤 · 宽 1.2 格 · 7 格/s
         ↗      ↑               破防 35% · 流血 15/s·3s
   ← ── ●玩家 ── →              道数 = 当前飞剑数
         ↘      ↓
           ✦  ↓  ↓
              ↘  ↘
```

- **几何**：飞剑绕身圆周旋转，碰撞即伤，完全免瞄准；剑阵的 `cooldown` 语义 = 转一圈的周期。
- **剑阵满级**：6 把 ×21 / r1.45 格 / 3.93 rad/s / 活 2 圈 / 冷却 3.20s / ≈118/s
- **斩罗决**：8 把 ×50 / r2.2 格 / 7.0 rad/s / 活 2.2 圈 / 冷却 1.97s；剑气每 4s ×8 道 / ≈700/s（+47%，融合必须赢得看得见）
- **强**：贴身自动生效；**弱**：打不到远处炮台 → 由斩罗剑气补洞

## ④ 扇面沙浪：厚土术 → 山崩地裂（cone）

```
 厚土（满级）                      山崩地裂（进化）
      ╱ ▔▔▔▔ ╲                      ┃▔▔▔▔▔▔▔▔▔▔▔╮
    ╱   ③   ↑  ╲                    ┃ ④          ║ ← 崩墙 3s（阻挡带）
玩家●━━━ ②  ↑    ╲               玩家●━━━━ ③      ║    挡怪不挡人
    ╲   ①   ↓  ╱                    ┃ ②  ↑      ✦ ← 撞墙: +40 + 眩晕0.6s
      ╲ ▁▁▁▁ ╱                      ┃ ①  ↓      ║   （全体系唯一硬控）
                                    ┃▁▁▁▁▁▁▁▁▁▁▁╯
 扇角 55°→90° · r3.5格              扇角 180° · r4.5格 · 4段
```

- **几何**：扇面**分段推进**——单只怪被推着依次穿过每段、各结算一次；群体吃一次扇扫。敌人被向外推挤（与龙卷的牵引方向相反，刻意互为反制）。
- **厚土满级**：12 伤 · 命中上限 6 / 冷却 1.20s / 扇角 90° / r3.5 格（试玩后砍半）/ 3 段 / 推 1.2 格 / 减速 25%·2s / 满级起打落敌弹
- **山崩地裂**：15 ×6 / 冷却 1.05s / 扇角 180° / r4.5 格 / 4 段 / 崩墙 3s：弧形阻挡带，被推上墙者 +40 伤 + 眩晕 0.6s；Boss/精英推距与撞伤减半
- **口径**：单体 30（五路最低），强度按**常态群伤（典型命中 4 个）≈120/s** 对齐——误按单体配表会配爆约 4 倍
- **强**：全体系唯一位移控制，推挤聚怪对火海/剑阵是乘法增益；**弱**：免疫击退目标无效（T8 窥涅修士）

## ⑤ 连锁雷弧：五雷正法 → 五雷轰顶（chain）

```
   ┌╌╌╌╌╌╌╌╌╌╌╌╌╌┐ ← 链距 3.5 格（全局最重要的平衡参数）
   ╎   ◆1 ⚡23    ╎
   ╎    ╲⚡0.85   ◆3 ⚡17 〰 感电×3
   ╎     ◆2 ⚡20   ╎
   └╌╌╌╌╌╌╌╌╌╌╌╌╌┘
          ⚡ 逐跳衰减 · 瞬时命中无弹道

   五雷轰顶: 4 道 · 跳 7 · 衰减 0.88 · 感电 5 层(+8%/层)
        │
        │ 天雷引: 每 2s · 80 伤 · 无递减
        ▼
      ◆满层目标   ← 优先点名「感电满层且血量最高」（自动集火精英/Boss）
```

- **几何**：瞬时锁敌，雷弧在 3.5 格链距内逐跳弹射，逐跳衰减；无飞行时间，空间上不可躲（与火球的弹道形成对照）。
- **五雷满级**：23 ×3 道 / 冷却 1.30s / 跳 5 / 衰减 0.85 / 感电 3 层 · 3s · +6%/层 / 单体 ≈53/s
- **五雷轰顶**：26 ×4 道 / 冷却 1.15s / 跳 7 / 衰减 0.88 / 感电 5 层 · 4.5s · +8%/层 / 天雷引：每 2s 降雷 80 伤，无视递减
- **设计约束**：感电只强化雷系自身、不给任何控制——避免与通用遗物「定身术」撞车；单体补强全靠天雷自动点名

## ⑥ 弧带龙卷：龙卷 → 仙术·呼风（arc）

```
 龙卷（满级）                    仙术·呼风（进化）
        ↗                              ↗ ↖
      ⟋   50°窄弧 ×3                ↗       ↖
玩家●━⟋ ← 外卷45°·弧径3.5格       ←  ●玩家  →  ← 主龙 ×1.5 = 39（正前）
移动方向 → 决定弧向                ↙       ↗
        ↘                              ↙ ↗
                                8道黑龙 · 每45°一道 · 外卷90°
 牵引 0.8 格: 把怪往弧线内侧搅     吹熄: 血量<20% 直接抹除
```

- **几何**：一段有厚度的圆弧从脚下向外旋卷推进，敌人被前缘、后缘各结算一次（单怪一次释放最多吃 2 次）。弧向由**释放瞬间的移动方向**决定——全体系唯一把「去哪打」交给脚下动作的法术。
- **龙卷满级**：22 ×3 道 / 冷却 1.30s / 单道 50° 宽（`arcWidth`，相邻道间留空档）/ 散布 220° / 弧径 3.5 格 / 外卷 45° / 牵引 0.8 格 / 单体 ≈33.8/s
- **仙术·呼风**：26 ×8 道 / 冷却 1.70s / 8 道首尾相接覆盖全周（刻意不填 `arcWidth`）/ 外卷 90° / 主龙 ×1.5 = 39（唯一可主动瞄准的一道）/ 吹熄：<20% 血量直接抹除（不动掉落）/ 牵引 0.8 格
- **⚠️ 全体系唯一「进化后单体反而变弱」**：33.8 → 30.6（正前吃主龙也只有 45.9）——8 道分散的固有代价，换全周覆盖 + 清尾效率；群伤 ≈229/s（基础形态 ×2.26，落在全局「进化约 ×2.2」基准上）

## ⑦ 纵深落锥：黄泉升窍诀 → 道化黄泉（drop → wave · aim: facing）

```
黄泉升窍诀（满级）                        道化黄泉（进化）
              ▽        ▽        ▽          ┌─────────────────────┐
              ▽        ▽        ▽          │ ≋≋≋≋ 水浪推进 ≋≋≋≋≋ │▶
玩家●━━━━━━━━◎━━━━━━━━◎━━━━━━━━◎        ●━━└─────────────────────┘
            2格      +1.6格    +1.6格         3格宽 × 5.5格长
  每点: 预警0.4s → 坠锥0.18s → 圆爆r1.4格    前沿0.3s扫过 · 残留1.5s只减速
  三道依次落下（间隔0.2s）·落点施放瞬间锁定   单怪整阵只结算1次
```

- **几何**：一串定点圆爆沿面向纵深排开——首点 2 格、道距 1.6 格，弹体**从天而降**（全体系唯一「落」类）；落点在**施放瞬间**锁定，不追踪。进化后整片换成贴身前推的矩形水浪。
- **黄泉升窍诀满级**：40 ×3 道 / 冷却 1.60s / 爆炸半径 1.4 格 / 预警 0.4s / 依次落下（间隔 0.2s）/ 冰缓 20%·1.5s（5 级起）；3 级第 2 道、5 级第 3 道 + 冰缓
- **道化黄泉**：55 / 冷却 1.60s / 矩形 3 格宽 × 5.5 格长 / 前沿 0.3s 推进 · 残留水洼 1.5s（每 0.4s 刷新冰缓 30%·2.0s，**只减速不伤**）
- **⚠️ 单怪一次施放只吃 1 道**：道距 1.6 格 < 爆径 2.8 格，相邻圆必然咬边——去重表按**单次施放**记账，否则 3 道全中会把群伤凭空 ×3
- **口径**：AoE 路线按常态群伤——典型 4 个 × 40 ÷ 1.60 = **100/s**；进化 7 个 × 55 ÷ 1.60 ≈ **240/s**（≈ ×2.4）。与火海分野：火海烧地板**只伤**，水洼**只控**——伤害区生态留给火海
- **尊魂幡**（专属遗物）：每级伤害 +10% → 满级 **+50%**、冰缓 **+10%**（叠至 30%）；5 级即融合钥匙
- **强**：纵深覆盖 + 预警圈诚实可读，压着怪潮来的方向接力砸；**弱**：单体被去重锁死（一次最多 40），近身 0.6 格内是安全区（首点 2 格 − 爆径 1.4 格），贴脸怪只能靠队友

## 七条路线的分化轴

| 轴 | 分化 |
|---|---|
| **瞄准** | 自动锁敌（火球 / 五雷）· 玩家面向（寂灭指 / 厚土 / 黄泉）· 走位即瞄准（龙卷）· 完全免瞄准（剑阵） |
| **控制方向** | 推挤（厚土，向外散）vs 牵引（龙卷，向内聚），刻意互为反制；黄泉零位移、只有冰缓泡慢；全体系唯一硬控 = 山崩撞墙眩晕 |
| **单体 vs 群伤** | 剑阵/五雷靠进化补单体短板；呼风反其道主动放弃单体，换全周覆盖 + 吹熄清尾；黄泉用「单怪一次只吃 1 道」把单体锁死在 25/s |
| **配表口径** | 厚土/龙卷/黄泉是 AoE 路线，按「常态群伤」对齐基准而非单体 DPS——混用口径是数值最容易配爆的地方 |
