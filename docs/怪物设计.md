# 《仙逆·幸存者》怪物设计文档

> 设计目标：把《吸血鬼幸存者》"海量杂兵 + 定时 Boss + 阶级递进"的怪物体系，翻译成《仙逆》的修真世界观。
> 怪物按**修真境界**从低到高排布，让玩家在 30 分钟一局内，体验从"凝气散修"一路杀到"窥涅巅峰"的进阶爽感。
> **境界上限锁定为「窥涅」**：不出现净涅/空涅/空灵等更高境界，也不出现任何"界外之族/界外修士"类怪物（界外设定整体剔除）。

---

## 一、设计理念：怪物如何映射修真体系

| 吸血鬼幸存者原型 | 仙逆化改写 | 设计意图 |
|---|---|---|
| 蝙蝠 / 僵尸（基础杂兵） | 凝气散修、阴魂、低阶灵兽 | 数量多、血薄、无脑冲锋，提供基础经验 |
| 高速小怪（蝙蝠） | 御剑飞行的小妖、蚊兽幼体 | 逼迫玩家走位 |
| 重甲怪（装甲兵） | 傀儡卫、玄武龟壳 | 高减伤，逼迫玩家堆穿透/真实伤害 |
| 远程怪（法师） | 结丹火修、雷修 | 站桩放技能，需要走位回避 |
| 分裂怪（史莱姆） | 尸傀、魔气化身 | 击杀后分裂，清场难点 |
| 召唤怪（骨龙） | 驭兽师、鬼修 | 持续制造新杂兵 |
| 精英（金色怪） | 妖兽之王 / 元婴老怪 | 高经验、掉特殊材料 |
| Boss（定时刷新） | 化神尊者、天运子、凌天侯、战老鬼、古神残灵 | 阶段性压力顶点（均不超过窥涅） |

**核心节奏**：经验掉落 = "悟道点"，金币 = "灵石"，Boss 掉落 = "法宝残片 / 神识结晶"，用于局外永久强化。

## 五、Boss 图鉴（定时刷新，均不超过窥涅）

Boss 在一局固定时间出现，击杀后短暂清场并掉落**神识结晶**（大额经验）+ 专属法宝残片。

| 时间 | Boss | 出处/身份 | 阶段机制 | 掉落（法宝残片） |
|---|---|---|---|---|
| 10:00 | **朱雀（成体）** | 朱雀星守护神 | 三阶段：火羽扇→火雨→浴火重生（半血回满，新增**环形羽爆**：360° 无缺口，逼玩家主动穿幕） | 朱雀之心 |
| 15:00 | **凌天侯·剑尊分身** | 天运星大罗剑宗开派老祖（净涅后期，实为灭生老人外放的监视分身） | 三阶段：**剑域**随阶段扩大（140→210→300px，站在域内持续掉血）+ **剑肖十二子**召唤围堵 | 凌天侯剑意 |
| 20:00 | **天运子·分身** | 罗天星域天运宗主（问鼎级） | 天运·命数：随机强化全场小怪+自身无敌闪现+**命数指**（巨型虚化手指从天而降，慢节奏重击） | 天运珠 |
| 25:00 | **战老鬼** | 战之规则化身（窥涅巅峰） | 狂暴冲锋+战意领域（范围内怪全加速） | 战魂幡 |
| 30:00 | **古神残灵·窥涅巅峰** | 古神陨落之主魂（古神之墟守关） | 多重神识波+反弹领域+召唤古神碎片 | 古神之心 |
| 30:00+ | **天逆珠·寂灭器灵（窥涅圆满）** | 天逆空间终极（无限模式 Boss） | 规则叠加：定身+拉拽+全屏弹幕 | 逆之核心 |

> 设计要点：Boss 不能只是"血厚"，每个 Boss 必须带一个**改变玩家走位习惯的机制**（火雨/冰封/拉拽/定身/反弹），迫使玩家在 Build 之外靠操作续命。所有 Boss 境界均封顶于窥涅，不引入界外存在。
>
> **招式类型学（实现口径见 `src/config/BossConfig.ts`）**：Boss 的每一招应归入一道**不同的走位题**，而不是"更多子弹"。
> `fan` 火羽扇 = 一道有缺口的扇形，考"往哪侧缺口走"；`nova` 环形羽爆 = 360° 无缺口的一整圈，考"往哪个方向冲、何时穿幕"——它是唯一不给安全区的招；`rain` 火雨 = 地面预警圈，考"放弃哪块地"；`finger` 命数指 = 头顶落下的巨型圈，考"别停下、且要抬头看天"；`fate` 命数 = 镀金小怪，考"先清谁"；`blink` 闪现 = 瞬移无敌，打断站桩输出。
> **前摇**：有弹幕的招（fan/nova/rain）出手前有约 0.3s 前摇，Boss 会脉动发光预告——玩家据此预读，而不是等弹幕出现在脸上；无弹幕的招（fate/blink/finger）不设 Boss 前摇——`finger` 自带 1.5–1.7s 的下降预告（落点圈收缩 + 巨指从天而降），比 0.3s 更足以读，再叠前摇只会拖沓。
> **`finger` 与 `rain` 的区别**：两者都是"地面预警圈"，但威胁来向相反 —— `rain` 从**天上掉小火点**、体量零碎，考"放弃哪块地"；`finger` 是**一整根巨指压下**、体量压迫，且带落点提前量（朝玩家移动方向外推 `leadPx`），考"别直线跑"。因此 `finger` 单发**慢**（8.2–11s）但**重**（单次 30–38 伤，躲开即无事，非持续灼烧），多根时沿玩家速度的法线左右均分，形成"合围"而非"随机撒点"。
> **`domain` 剑域（凌天侯专属）**：与 `rain`/`finger` 的"一次性预警圈"不同，剑域是**跟着 Boss 每帧移动的持续危险区**，半径随阶段突变（140→210→300px）。它把"离 Boss 多远"从一个被动结果变成主动选择：贴着他打 DPS 最高但每秒掉血（16→22→30 dps），退到域外安全但命中率与 DPS 都掉——这是三只 Boss 里唯一一道**空间取舍题**，而不是反应题。判定在 `BossSystem.syncDomain` 每帧算距离，**不走 physics overlap**（擦边时反复进出会让掉血变成抖动）。⚠️ 硬约束两条：①`tickMs` 必须明显短于玩家 600ms 无敌帧（配 480–500），否则一半 tick 被吞、dps 变成随机数；②贴图缩放分母 `SWORD_DOMAIN_TEXTURE_RADIUS` 必须等于 `fx_sworddomain` 的实际内容半径，视觉圈与判定圈错开比没有圈更糟。
> **`summon` 召唤（凌天侯专属）**：周期召出**剑肖十二子**（原著里他以十二生肖命名的弟子，纸面修为强、实战弱）。他们本身是普通杂兵档（`sword_disciple`，150 血），威胁来自"剑尊在背后"——作用是**打断玩家退到域外慢慢磨的算盘**。落点沿首领环形均分而非随机：随机撒会在同侧堆成一坨，玩家绕到另一侧就没了压力。`maxAlive` 按阶段 6→10→12 递增（全场上限，呼应"十二子"）。`approach: 'summon'` 让他们**不进常规刷怪表**（见 `WaveConfig` 可达性自检）。
> **弹体外观**：Boss 弹道一律用专属贴图（朱雀火羽 `proj_fire_feather` / 狂暴 `proj_fire_feather_rage`、天运子签文、凌天侯剑气 `proj_boss_sword`），不复用术修的 `proj_enemy_shot` 小圆点——首领的点名必须一眼可辨。**外观不放大碰撞判定**：火羽画 30px，碰撞圆仍与圆弹同为 4px。三只 Boss 的弹体色相各据一方：朱雀橙红 `0xff6622` / 天运子淡青 `0x66ddcc` / 凌天侯青灰 `0x9db4d0`。

## 七、怪物行为模式分类（供程序与配表参考）

1. **冲锋型**（散修劫匪、窥涅修士）：朝玩家直线/斜线移动，碰触伤害。占杂兵 60%。
2. **飞行穿插型**（飞天僵尸、御剑小妖）：空中轨迹，绕圈后突刺，逼迫玩家预判。
3. **远程炮台型**（雷蛙、邪修咒师）：站桩或慢移，发射可预警弹道，需走位。
4. **自爆型**（火蚁卫）：死亡触发小范围 AoE，清场时反伤。
5. **分裂型**（引气灵兔、魔气化身）：击杀分裂 2–3 个弱体，制造滚雪球。
6. **召唤型**（鬼修、化神尊者）：周期性生成新杂兵，拖慢清场。
7. **反伤/控制型**（古神残魂、古神之灵碎片）：反弹伤害或定身/拉拽，针对无脑莽夫流。
8. **双体型**（婴变老祖）：本体高减伤、元婴脱体远程施法，需同时击杀两部分，否则本体复活元婴。
9. **资源掠夺型**（魔婴修士）：不直接高伤，而是削减玩家经验获取（吞噬灵气）/ 减速，逼迫优先点杀。
10. **Boss 机制型**：每个 Boss 绑定 1 个全场机制（见第五节）。

## 八、与 Build 的克制关系（预告）

- 纯近身 AoE（如"寂灭指"贴脸）会被**反伤型**克制 → 需搭配穿透/远程。
- 站桩炮台流被**高速穿插型**克制 → 需位移/击退法宝。
- 无脑堆血被**噬魂鬼修（掉血上限）**克制 → 需回春/复活。
- 控制流（定身术）被**古神残灵·反弹领域**克制 → 需备用输出。
- **双体型**（婴变老祖）考验"分兵"能力：纯 AoE 铺场流（火海）会被两部分摊薄，单体贯穿流（化魔指）更优。
- **资源掠夺型**（魔婴修士）会吞噬玩家击杀掉落的灵气、削减经验获取，必须优先点杀，否则整局升级节奏被拖垮。
- **位移控制流**（厚土术的推挤聚怪、崩墙封路）被 **T8 窥涅修士「免疫击退」**克制 → 古神之墟 / 天逆空间以 T7–T8 怪池为主，推挤失效、只剩崩墙阻挡。可选解法见《build设计.md》第七节 ④ 的 ⚠️ 说明。
- **自爆型 / 分裂型**（火蚁卫、引气灵兔）被**推挤流**天然克制 → 先推离再点杀，让自爆与分裂体都生成在远离玩家的位置。
- **连锁 / 感电流**（五雷正法）的收益与**怪群密度**严格正相关 → 在密集杂兵群与**分裂型**上收益极高（感电在分裂体上瞬间铺开）；但在**精英 / Boss 单体**与稀薄怪群上收益断崖（连锁递减对单目标不生效），必须靠进化「天雷引」或其他法术补单体。
